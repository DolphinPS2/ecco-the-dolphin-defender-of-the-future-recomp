# Шпаргалка и план развития (v1.5 -> v1.6)

## Что реализовано в v1.5-beta (Windows)
- **Исправлен перенос перевода Paradox RUS:** извлекаются только 48 файлов уровней (`.GDE`), а сломанные `MUSIC_*.AFS` и `SOUND` удаляются автоматически — работает русская озвучка, шрифты и полная оригинальная музыка.
- **Поддержка образов без внешних библиотек:** нативный парсер `.cdi` и `.gdi`, а также распаковка `.chd` через `chdman.exe`.
- **Чистая перезапись при повторном запуске:** перед новым переносом перевода папка `mods\rus_paradox` полностью очищается от старых файлов.
- **Обновлённый 2K-лаунчер:**
  - Автоподнятие окна поверх Проводника при старте (64-битный WinAPI `AttachThreadInput` + `SetWindowPos`) и автоскрытие системного курсора при запуске.
  - Подводная волна с дышащей прозрачностью и пузырьками прогресса (отображается только при выборе Русской Версии по `F2` / `Y`).
  - Живой подводный маячок **`SEGANET • DREAMPIPE.NET`** (`https://dreampipe.net`) в глубине между кнопками.
  - Неблокирующий диалог выбора образа в отдельном процессе и запуск игры с геймпада по кнопке **Start** (`7/9/11`) и **A** (`0`).

## Задачи на следующую версию (v1.6)
1. **Обновление сборки для Linux (`linux_v14_work` -> `linux_v15`):**
   - Перенести обновлённый `extract_paradox_mod.py` (с фиксом музыки и поддержкой `.cdi/.chd/.gdi`) в Linux-пакет.
   - Адаптировать `launcher.py` под Linux (выбор файла через `zenity`/`kdialog` вместо PowerShell, запуск нативного бинарника без `ctypes.windll`).
   - Обновить скрипт `Ecco_the_Dolphin_Linux_Setup.run` на актуальный тег релиза.
2. **Менеджер сохранений VMU в лаунчере (`F3 / X`):**
   - Экспорт и импорт карты памяти `vmu_a1.bin` (128 КБ) с автоматическим резервным копированием (`vmu_a1.bin.bak`).
   - Перепаковка и импорт отдельных слотов сохранений `.VMI` / `.VMS` (совместимость с Flycast, Redream, GameFAQs и реальной VMU).
   - Клонирование прогресса между профилями `Europe` и `Paradox RUS` в один клик.
3. **Мелкий полиш UI и движка:**
   - Доработать повторное скрытие системного курсора после движения мышью при возврате на стик/крестовину геймпада.
   - Интерактивный HD-оверлей экрана VMU в C++-движке по нажатию шифтов (`LB` / `RB`).
