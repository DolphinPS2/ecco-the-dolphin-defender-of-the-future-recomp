# База знаний: критические баги, ловушки сборки и их решения (Windows & Linux)

Этот документ обязателен к прочтению перед любой пересборкой движка, лаунчера или установщиков.

---

## 1. Linux: старое консольное меню (`CONTROLLER`) вместо современного русского оверлея
- **Симптом:** При нажатии `Esc` / `Select` в игре открывается старый оранжево-белый оверлей `CONTROLLER` вместо современного меню с вкладками `Общие | Управление | Графика | Звук | Моды`.
- **Причина:** Бинарник движка был скомпилирован с `-DDREAMCOMP_FRONTEND=OFF`, либо не применён патч `patches/dreamcomp_ru_menu.patch`, либо в папке `engine/frontend/` отсутствуют `lang_ru.ini` и папка `fonts/`.
- **Решение:**
  1. Применить `git apply ports/ecco-the-dolphin-defender-of-the-future-recomp/patches/dreamcomp_ru_menu.patch`.
  2. Конфигурировать CMake строго с `-DDREAMCOMP_FRONTEND=ON`.
  3. Скопировать в `engine/frontend/` как словарь `frontend/lang_ru.ini`, так и сгенерированную папку шрифтов `build/game/frontend/.`.
  4. Лаунчер должен передавать `APPDATA` и `XDG_CONFIG_HOME` с подстрокой `paradox_rus` для включения русского языка.

## 2. Paradox RUS: пропадает фоновая музыка в русской версии
- **Симптом:** В русской версии работают озвучка и шрифты, но во время плавания тишина (нет музыки).
- **Причина:** На пиратском образе Paradox лежат обрезанные/сломанные аудиоархивы `MUSIC_*.AFS`.
- **Решение:** Скрипт `extract_paradox_mod.py` должен:
  - Полностью удалять старое содержимое `mods/rus_paradox` перед каждым новым переносом.
  - Извлекать **строго 48 файлов уровней (`.GDE`)** и полностью игнорировать `MUSIC_*.AFS` и `SOUND` (тогда музыка берётся из оригинального европейского образа).

## 3. Windows Sandbox / чистая Windows: вылет `FileNotFoundError` при старте лаунчера
- **Симптом:** На чистой системе (без установленного в системе FFmpeg) лаунчер падает с `FileNotFoundError: [WinError 2]` на строке запуска `intro_2k.mp4`.
- **Причина:** В папку `runtime/` был положен только `ffmpeg.exe`, а `ffplay.exe` вызывался из `PATH`.
- **Решение:** В `runtime/` должны лежать оба файла (`ffmpeg.exe` и `ffplay.exe`), а вызов заставки защищён проверкой существования.

## 4. Windows: пропадающий курсор и самопроизвольный запуск игры мимо лаунчера
- **Симптом:** Системный курсор исчезает после клика, а на мониторах с масштабированием (или в Sandbox) лаунчер сразу запускает игру при открытии.
- **Причина:** Использование WinAPI-подмены курсора (`SetSystemCursor` / `SystemParametersInfoW`) и фейкового клика `mouse_event` по центру экрана при инициализации.
- **Решение:** Никогда не подменять системный курсор Windows и не эмулировать клики мышью. Использовать стандартный курсор Pygame, `win.focus()` и задержку `t_anim > 0.5` на кнопки запуска с геймпада/мыши.

## 5. Linux (KDE Plasma / Wayland): ошибка выбора диска и браузер позади окна
- **Симптом 1:** При нажатии `[F2 / Y]` вылетает ошибка `expected str, bytes or os.PathLike object, not list`.
  - **Решение:** В `shutil.which(cmd[0])` передавать имя команды (`cmd[0]`), а не весь список аргументов `cmd`.
- **Симптом 2:** При клике на `SEGANET • DREAMPIPE.NET` браузер открывается под полноэкранным окном лаунчера.
  - **Решение:** Вызывать `win.minimize()` перед `webbrowser.open(...)`.
- **Симптом 3:** При распаковке `.zip` на Linux появляются файлы с обратным слешом в имени (`media\ocean_2k.mp4`).
  - **Решение:** При упаковке архивов на Windows всегда делать `.replace("\\", "/")`.

## 6. GitHub Actions CI (`test_windows.yml`)
- **Правило:** Воркфлоу автотеста ищет в релизе файл с точным именем `Ecco_the_Dolphin_Online_Setup.exe` (без суффикса версии `_v15`). При публикации нового релиза всегда прикладывать либо копию с этим именем, либо обновлять `.github/workflows/test_windows.yml`.
